## Range 0.1.1

Range quitte le Dock et partage une seule icône de barre des menus avec vos autres apps vialet.app.

- Plus d'icône dans le Dock par défaut : elle n'apparaît que pendant qu'une fenêtre de Range est ouverte. Nouveau réglage « Icône dans le Dock » : Fenêtre ouverte, ou Toujours.
- Seule app vialet.app de ce Mac, Range garde son icône dans la barre des menus ; avec d'autres, une seule icône vialet.app les rassemble, même sans l'app Vialet.
- Ce menu rassembleur montre vos apps, leurs actions rapides et leurs mises à jour.
